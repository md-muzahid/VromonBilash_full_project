## Testing Scope

### 1. Manual Testing and Test Case Design
- Requirement analysis and test planning
- Writing and reviewing test cases
- Test execution and result evaluation

### 2. Bug Reporting
- Documenting defects with steps to reproduce, expected and actual results, and severity
- Tracking bugs and root cause analysis

### 3. API Testing
- Verifying backend system interactions, request and response validation, and status codes

### 4. Load and Performance Testing
- Assessing system behavior and response under high usage

### 5. Cross-Browser Testing
- Checking that the application works consistently across browsers

### 6. Mobile and OS Testing
- Verifying behavior across different devices and operating systems

### 7. Payment Gateway Testing
- Validating successful and failed payment scenarios

### 8. Security Testing
- Identifying common security weaknesses
